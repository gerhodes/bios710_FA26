# BIOS-710 Statistical Genetics and Genetic Epidemiology (FA2026)

# Activity for Intolerance Lecture

For this activity, you will need to read the file "gnomAD_gene_counts_subset_RVIS.tsv" into your R environment. This file contains the pre-computed per-gene counts for common functional variants and all protein-coding variants needed to fit the linear model to get RVIS from gnomAD v.4.1 exome data on chromosomes 19, 20, and 21. You don't need to worry about the filtering steps that were taken to generate this data file, but the processing scripts are also provided here in case you are curious. Note: because we are only fitting the linear model to a subset of the genome, our results will be for illustration purposes only.
